# تطبيق جدول المحاضرات (أندرويد) - النسخة 3

## تحديث التطبيق الموجود على GitHub

1. فك ضغط الملف. افتح مستودعك على GitHub ثم Add file ثم Upload files.
2. اسحب كل محتويات المجلد (www و assets و scripts و android-extra و package.json و capacitor.config.json و .gitignore و build-apk-workflow.yml) واضغط Commit changes. الملفات القديمة تُستبدل تلقائيًا. مجلد www يحتوي مجلد vendor (محرك قراءة الصور) ولا يصح حذفه.
3. حدّث ملف البناء: افتح المسار .github/workflows/build-apk.yml في المستودع، اضغط علامة القلم (Edit)، امسح المحتوى والصق محتوى الملف build-apk-workflow.yml، ثم Commit changes.
4. افتح تبويب Actions وانتظر انتهاء العملية (علامة صح خضراء)، ثم نزّل lecture-schedule-apk من قسم Artifacts.
5. احذف النسخة القديمة من الهاتف قبل تثبيت الجديدة، وسجّل جدولك قبل ذلك لأن الحذف يمسح البيانات المحفوظة.

## أول تشغيل

- عند فتح التطبيق سيطلب الهاتف السماح بالإشعارات. اضغط السماح.
- من القائمة الجانبية افتح التنبيهات واضغط إرسال تنبيه تجريبي للتأكد أن الإشعار يظهر.
