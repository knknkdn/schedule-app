# جدول المحاضرات — تطبيق أندرويد أصلي (Kotlin)

هذا المشروع مكتوب بلغة أندرويد الأصلية، فيفتح فورًا مثل بقية التطبيقات (بدون WebView).

## بناء التطبيق (APK) عبر GitHub
1. أنشئ مستودعًا جديدًا في GitHub (يفضّل مستودع جديد باسم `jadwal-native`).
2. ارفع **كل** محتويات هذا المجلد إلى المستودع (بما فيها المجلد المخفي `.github`).
3. افتح تبويب **Actions** وانتظر انتهاء «Build APK» (بضع دقائق).
4. ادخل على التشغيل المكتمل، ونزّل الملف `jadwal-apk` من قسم **Artifacts**، وفك الضغط لتجد ملف `.apk`.
5. انقل الملف إلى الهاتف وثبّته (اسمح بالتثبيت من مصدر غير معروف إن طُلب).
