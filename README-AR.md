# تطبيق جدول المحاضرات (أندرويد)

هذا المجلد يحتوي على التطبيق كاملًا. لا تحتاج لتثبيت أي برنامج: GitHub يبني ملف الـ APK لك مجانًا.

## الخطوات (من الحاسوب)

1. أنشئ حسابًا مجانيًا في github.com ثم اضغط New repository، واكتب أي اسم (مثلًا schedule-app) واضغط Create repository.
2. فك ضغط الملف، ثم في صفحة المستودع اضغط Add file ثم Upload files، واسحب إليها كل محتويات المجلد (www و assets و package.json و capacitor.config.json و .gitignore) ومعها المجلد المخفي .github، ثم اضغط Commit changes.
3. اذهب إلى تبويب Actions. سيبدأ البناء تلقائيًا (أو اختر Build APK ثم Run workflow). يستغرق نحو 5 إلى 10 دقائق.
4. عند ظهور علامة صح خضراء، افتح العملية وانزل إلى قسم Artifacts ونزّل lecture-schedule-apk.
5. فك ضغط الملف المحمّل، وأرسل app-debug.apk إلى هاتفك وافتحه. اسمح بالتثبيت من مصدر غير معروف عندما يطلب الهاتف ذلك.

## إذا لم يظهر المجلد المخفي .github

أنشئ الملف يدويًا: اضغط Add file ثم Create new file، واكتب في خانة الاسم:

.github/workflows/build-apk.yml

والصق فيها محتوى الملف الموجود في هذا المجلد بنفس المسار، ثم Commit changes.

## ملاحظات

- لتحديث التطبيق لاحقًا: استبدل ملف www/index.html في المستودع، وانتظر البناء الجديد. احذف النسخة القديمة من الهاتف قبل تثبيت الجديدة، لأن كل بناء يُوقَّع بمفتاح مختلف. هذا يمسح الجدول المحفوظ، فسجّل جدولك قبل التحديث.
- الجدول يُحفظ على الهاتف نفسه ولا يحتاج إنترنت.
